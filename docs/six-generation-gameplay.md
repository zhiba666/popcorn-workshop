# 六代工厂玩法设计 · 自动供货与棋盘合成版

## 1. 文档定位与适用范围

本文统一定义六代工厂的生产、流水线、库存、棋盘操作、升阶、并行订单、顾客与离线规则，并保留原型验证及验收边界。已确认规则、待验证目标和待定事项分别记录；文档不代表这些功能已经实现或通过试玩。

多流水线、独立库存、并行订单与横滑界面、发射器、升阶折算、免费丢弃及逆向拆分尚未实现、尚未试玩验证。现阶段仅整理设计文档，不修改游戏源代码，不制定完整经济数值表，也不实施数值模拟。

内容范围止于第六代，不增加第七代及之后的设计；不增加手动生产调度、配方探索、辅料库存或维护惩罚。顾客扩展范围见第9章，尚未确定的规格集中列于第13章。

项目面向抖音小游戏，开发与目标平台验证遵循[项目约定](../README.md)。工厂页面的空间、视觉与具体控件遵循[工厂主页面设计](factory-main-page-design.md)；本文负责玩法及计算口径。

## 2. 核心体验与统一术语

### 2.1 核心循环与体验目标

成长主线为：

**横向浏览并行顾客订单，选择当前关注目标 → 各流水线按自身出厂等级自动生产并进入独立库存 → 点击或长按所选发射器，逐份出货到棋盘 → 同种同级二合一，可跨线合成，按需使用已开放的逆向拆分 → 手动交付棋盘上的匹配成品，获得金币并推进顾客图鉴，刷新其他订单进度 → 提升产能、单线升阶、增开同种流水线或扩建新产品。**

工厂负责持续供货与经营成长，棋盘合成承担主要主动玩法，订单提供目标与集中回报。核心乐趣是物品升级、合成腾位与订单接近完成，交单后再通过投资改善供货、提高合成起点或扩充流水线。同种产品的各线可以保持不同出厂等级，玩家选择低阶供货线或高阶主力线取货。出厂升阶让工厂直接提供曾经需要反复合成的规格；六种产品仍各有独立合成链，增开同种流水线不新增产品类别。公共供料与包装由系统处理，不要求玩家手动调度，具体分配规则待定。

顾客图鉴承担长期收集与熟客养成：认识新顾客扩充收藏，多次完成同一顾客的订单提高其星级，达到节点获得一次性奖励。顾客直接附着于现有订单，本版只包含顾客身份、图鉴、服务次数、升星与奖励，不展开额外顾客玩法。

游戏以短时登录、在并行订单中选择适合当前材料与目标的一张或几张、完成一段合成和有感知的投资，以及自然退出和回归为主要体验；不要求一次完成全部订单。自动生产必须能够提供有效订单所需材料，玩家选择能供货的流水线发射到棋盘，完成必要合成后交付。即使仓库已有目标等级成品，也必须先发射才能计入齐货；金币仍由手动交付获得。点击加速是可选的补缺口能力，不与棋盘合成组成必须连续完成的两段重复劳动，不设置必须点击的次数或购买自动化的门槛。

六代在同一座工厂内成长：新代际解锁产品，同种扩线增加独立流水线，单线升阶提高合成起点。工厂持续提供材料，玩家在棋盘完成主要主动操作，通过并行订单的交付顺序和投资选择推进经营。

## 3. 产品内容、流水线与工厂成长

### 3.1 六代产品与加工特点

六代按顺序在同一座工厂内扩建，每代首次解锁一种产品及首条自动流水线，新产品增加合成链而不是让旧商品升一级。同种扩线沿用该产品工序，不增加产品类别。普通产能升级影响加工速度和批量，单线出厂升阶影响合成起点，两项分开表达。

下表描述各产品首次投产与加工特点。“原味流水线”“焦糖流水线”的规格指对应的单条线；同一种产品的多条线可以具有不同出厂等级。

| 代际 | 商品与设备 | 自动加工过程 | 这一代的主要体验与投资重点 |
|---|---|---|---|
| **一代：气爆作坊** | 原味杯／气爆锅 | 玉米自动送入，气爆锅鼓风使其爆开，成品转运并按原味流水线当前出厂规格包装入库，初始为一级 | 看懂自动供货、取货、二合一和手动交单；先感受产能投资，再通过原味出厂升阶第一次体验跳过熟悉的低阶合成 |
| **二代：裹糖工坊** | 焦糖桶／裹糖滚筒 | 一盘基础爆米花进入滚筒，自动翻滚裹糖，按焦糖流水线当前出厂规格包装入库，初始为一级 | 新增焦糖合成链，原味线继续供货；原味、焦糖流水线可有不同出厂等级，玩家选择投资供货、出厂升阶或下一条新线 |
| **三代：成球工坊** | 爆米花球／合模机 | 物料填入一排模具，压柄自动带动合模，完成后开模出球 | 散粒变成立体成品，多模同时出货；扩批也增加供料需求，需要在机器扩批与公共供料之间选择 |
| **四代：脆棒工坊** | 爆米花脆棒／压延切条机 | 压辊自动压平整片物料，随后切成脆棒并集中出料 | 集中出料更容易积满加工后的待包装缓存；玩家判断先提高加工能力还是加快包装，让合成所缺的出厂产品更早入库 |
| **五代：薄脆工坊** | 爆米花薄脆／双面烤模机 | 自动填模、烘烤、翻转整排烤模并脱模，各阶段连续衔接 | 分阶段加工形成不同运行节奏；玩家判断加工周期较长还是公共供料、包装不足，不需要守候翻面 |
| **六代：夹心工坊** | 夹心爆米花脆方／旋转组装台 | 转台自动推进，铺底、注芯、封层、出模在各工位同时发生 | 先填满流水线，再进入连续出货阶段；关注供料与包装能否支撑持续运行，看见整座工厂共同生产 |

### 3.2 商品等级与包装表达

- **等级表达成长：**同一产品的高等级通过单份商品更大体量、组合规格和更精致的包装表现，物品轮廓与体量应有明显变化。例如原味小杯、双杯装、分享盒、礼盒可作为外观方向，具体各级名称与美术另行细化；不增加配方试错或随机变种。每个完整包装均算一份对应等级的商品并占一格，格内标示种类与等级，例如“原味三级”；双杯装等包装内部组成不另外增加棋盘商品份数。

- **等级开放：**已开放的合成等级不要求额外购买合成权限。更高目标内容随成长分阶段开放，出厂升阶为更长的总等级链提供操作量基础；六种产品的代际与物品最高等级不绑定。

- **原型范围：**先验证一级起步到五级目标的基础循环，再加入出厂等级提升和更高目标，比较升级前后的同目标操作量。发射器与出厂等级上限固定为六级；商品等级上限及各阶段开放节点留待试玩确定。达到当前内容上限的物品不再合并。

### 3.3 同种扩线与独立供货

- **同种产品多流水线：**每种产品最多三条已投产流水线，每条新线从一级出厂开始，拥有独立加工设备、独立库存及对应发射器；各线同时生产，共用全厂供料和包装。同种扩线增加加工能力与供货规格选择，但实际增产仍受公共环节限制。各线库存不直接调拨、不自动共用，发射只扣所操作线的库存；上棋盘后商品按产品与等级统一使用，可跨线合并。取消回仓后，商品不能返回任何流水线库存。

- 每条流水线拥有一个常驻发射器，发射器等级与本线出厂等级一一对应，初始一级、最高六级；两者共用同一升级状态与费用，不另设第二套等级。
- 各线独立升阶。六级后不再开放更高发射器等级或出厂升阶；六级以上的已开放商品仍由棋盘合成。
- 升阶改变本线新批次规格并折算本线可用库存，其他同种流水线、其他产品和已有棋盘商品不随之升阶。完整转换规则见第6章。
- 同种线各自拥有加工能力，可同时生产；公共供料或包装受限时，实际增产不等于设备数量的简单倍增。

### 3.4 开局、新品扩建与基础自动化

开局提供已接入物流、可自动运行的初代基础产线，供料、气爆加工、转运、包装和入库形成完整循环。基础原料与设备内部辅料不另收金币，零金币时仍能继续生产；无需逐项购买自动供料、自动转运或自动加工功能。

首次订单由初始可来访顾客提出，只要求初代现有设备供应的一份原味产品，指定一个需要低等级合成的目标等级。引导围绕首批自动入库、取货、连续几次二合一、手动交单及第一笔产能投资展开，首次交付同时点亮该顾客图鉴；基础供货应支撑一段连贯的合成，不将点击练习或先浏览图鉴作为交单条件。

供料、加工、转运和包装的自动运行属于基础能力；升级购买的是更大的产能或更高的出厂初始等级，不单独收取自动化功能费用。

六代按顺序扩建。拥有下一代所需金币即可建设，不再附加自动加工购买、点击次数或指定订单数量条件；扩建资金通过交付订单积累。

新产品扩建包含首条流水线的基础机器、物流接入和启动所需公共配套产能，建好即自动生产，公共配套以维持旧线基础供货并支持新品启动为目标。同种扩线新增独立加工设备、独立库存和常驻发射器，最多三条，均从一级出厂起步；其开线条件、费用及公共配套暂不细化。独立加工可同时进行，供料和包装仍共用全厂能力，实际增产不等于设备数量的简单倍增。

### 3.5 投资方向与经营选择

金币只通过手动交付订单获得，包括订单收入及当次触发的顾客升星礼，可用于改善现有产能、单线升阶、增开同种流水线或下一代新品扩建。混合订单、同种不同规格供货和棋盘空间共同提供投资取舍：

| 投资方向 | 玩家判断的依据 | 投资带来的价值 |
|---|---|---|
| 公共供料 | 多台机器等料、入口空着 | 减少设备空转，支持更多流水线运行 |
| 流水线机器 | 待加工物料积压、加工周期长 | 扩大单批规模或缩短加工时间，提高加工能力 |
| 单线出厂升阶 | 从本线当前起点完成熟悉目标仍需较多低阶合并 | 提高本线默认出厂等级，只折算本线库存；其他同种线保留规格与库存 |
| 公共包装 | 待包装成品积压、合成所缺产品尚未入库 | 更快形成对应规格的可取用库存，缩短合成前的材料等待 |
| 同种扩线 | 比较追加独立加工能力、保留低阶供货或增建高阶主力线的价值 | 从一级建立新线和独立库存，增加一个常驻发射器；每种最多三条，仍受公共供料与包装限制 |
| 存钱扩建新品 | 距离下一代费用还有差额，比较其他投资与扩建用途 | 获得新产品、首条流水线与后续订单组合 |

扩建作为长期目标，与少量有明显效果的近期投资并存。近期投资应改善生产或备货效率，不将一次有效升级拆成大量微小购买来提高操作频率。金币不足且仍缺基础产品时，玩家可自然等待或自愿点击加速；不点击也能依靠自动生产备齐基础材料，再手动合成与交付。

## 4. 自动生产、公共物流与可选加速

### 4.1 生产关系与物料边界

采用以下供料结构作为草稿默认：

**公共基础爆米花供料 → 各条流水线按自身批次规格独立加工 → 公共包装 → 各流水线独立库存 → 对应发射器逐份出货到棋盘，一格一份 → 手动合成／已开放的拆分 → 手动交付棋盘匹配成品。**

气爆锅从开局起自动加工原料玉米，提供公共基础爆米花；原味杯是其中一条成品流水线。后续设备只使用尚未成为成品的基础爆米花，不消耗已经包装入库或用于交单的原味杯及其他商品。

原味成品流水线的升阶只作用于被升级线的成品规格与仓库折算，不改变公共基础爆米花，也不顺带提高其他原味线或其他产品线的出厂等级。公共供料的产能升级服务于全厂，同种原味扩线不把公共基础爆米花重复计作成品库存。

糖浆、黏合基料、烘烤基料和夹心由对应设备内部准备，本轮不增加辅料采购与库存管理。

半成品留在机器本地，完成加工后才进入公共包装队列，不为未完成品预占公共包装空间。某条流水线缺料或满缓存时，不闲置其他流水线可用的共享能力；已经开始的加工与包装正常完成，不被强行中断。在线与离线均遵守相同的生产关系和容量约束。

高阶出厂产品必须经过对应规格的真实加工与包装。按其代表的实际份量核算物料需求，批量、加工周期、缓存占用和包装能力使用同一套规格口径；不能把一件高阶大包装在所有环节都当成一件一级小包装而虚增产量。生产与包装耗时由设备能力和规格共同决定，不直接把一级等价数量当作所有环节的耗时倍率。升级预览应同时反映共享产能限制和合并次数的减少，具体配套数值留待模拟。

工厂批次规格、物料消耗、包装能力与实际入库份数按真实商品核算。每份入库商品取到棋盘后各占一格，棋盘空格只限制当前可取出的数量，不改变工厂的生产产量。

### 4.2 公共产能与安全等待

系统负责公共供料和包装调度，玩家不手动分配。各产品与流水线能持续获得必要供货是设计目标；公共能力不足时，基础份额按产品还是按流水线分配、余量如何分配均保留待定。本轮不预设均分、轮流或某种产品优先。缺料或满缓存的线不能阻塞其他可加工线，点击仍受相同公共能力和容量限制。

旧流水线满缓存时自动暂停，空间恢复后继续工作，不坏货、不要求维修。

### 4.3 机器自动运行的共同要求

所有机器都遵循：

- 从投产开始自动完成全部工序，点击加速按钮提供额外加工进展；停手或离开机器页面后继续自动生产，已经获得的进度保留。
- 机器动作对应真实批次和生产进展，玩家能看懂物料如何变成商品。
- 扩批、提速等升级应带来可感知的加工规模、运行节奏或实际出货变化，不依靠大量微小升级制造忙碌。
- 出厂升阶应改变对应流水线的新批次成品等级，并展示新规格的首批加工、包装与入库；对同一合成目标应有明确的操作量减少，不能仅换图标或升级名称。
- 缺料或满缓存时安全等待，条件恢复后自动继续；玩家离开不会造成烧坏、丢料或需要手动恢复的停机。

### 4.4 点击加速

棋盘承担主要主动操作，加速用于自愿缩短少量缺货等待。正常订单不要求先反复加速再反复合成，也不要求每合几次切回工厂补料。

- **入口与即时推进：**工厂主页面按配套设计先选中设备，再通过详情中的加速按钮操作；点击机器本身只选中，不叠加进度。每次有效加速立即推进当前真实可加工批次或工序，机器动作、进度与物料同步。
- **统一操作：**六代加工设备及公共供料、包装均使用点击加速，不增加复杂手势、精准时机、连击要求或手工批次。
- **保持生产约束：**仍须满足供料、工序顺序和缓存条件，商品须真实包装后才能入库。不直接发金币或凭空生成成品；没有可推进工序时说明缺料、堵塞等原因，不累计虚假产量或未来加速。气爆锅加速推进公共基础供料，不能直接算原味成品库存。
- **随设备成长：**单次有效推进量随设备等级、单批规模和加工能力成长，后期不能仍只有固定微小收益；具体增量待验证。
- **订单提示：**展示当前关注订单的产品缺口、目标等级、可供货线与真实瓶颈，并提供对应设备入口。切换关注不改变调度、不锁定材料。实际入库只刷新材料缺口；发射、合成或已开放拆分得到真实棋盘成品后才刷新齐货。
- **随时停止：**不设必须操作的时长、次数或购买自动化门槛，停止后已有进度保留且自动生产继续。订单规模、升级费用与正常节奏基于自动能力，不以持续点击为前提。

## 5. 棋盘、发射器与商品操作

### 5.1 占格、常驻与容量

- **固定操作台与常驻发射器：**棋盘横7列、竖9行，共63格。每格只容纳一份商品或一个发射器；每种产品最多三条线、每线一个发射器，全部常驻不可收起，各占一格且可移动。实际发射器数为 K 时，商品格总容量为63−K；六种产品各一条线时K=6、最多57份商品，各三条时K=18、最多45份商品。新增发射器须放入空格，满盘时先腾位，不覆盖商品。飞行动画锁定落点计入商品占用。工厂设备、各线库存和待统一入账记录位于棋盘外。

每份商品或每个发射器独占一格，高等级大包装仍是一份；包装内组成件数、生产批量、产能升级和升阶不改变这一规则。

各线数字仓库默认无容量上限，不增加付费扩仓。棋盘满只限制发射，不阻止工厂加工、包装和入库；机器本地及包装前缓存仍有容量限制，不能与棋盘空格混为一谈。

发射、移动、合并、已开放的拆分与丢弃不消耗金币或体力，不另设能量门槛。丢弃只损失选定商品。

### 5.2 发射与移动

- **生产入库：**正常新规格商品实际完成包装后，进入所属流水线的独立库存；升阶遗留旧批按后述旧批集合规则统一入账。库存不自动出售或产生金币，发射器只发本线当前出厂等级，每次一份，不设商品等级选择按钮。库存之间不能直接转移，仓库商品必须先发射到棋盘才能用于订单。

- **逐份发射：**玩家短按或长按指定发射器，每一发独立检查本线至少一份当前等级库存与一个空格；成功时同时扣本线一份库存、锁定落点并生成一份商品。飞行动画期间落点已占用，失败不扣库存。在没有补货、合并、交付或丢弃等变化时，连续可发份数为min(本线库存份数, 空格数)，不能借用其他线库存。发射不自动合成，也不预先预约整批未发商品。

- **发射器移动：**发射器可拖到棋盘空格，目标被商品或其他发射器占用时保留原位置，不覆盖商品。移动只改变发射器位置，不改变其对应产品或库存；落下时不发射。玩家不能指定发射区域，移动后的下一次发射以新位置寻找落点。

### 5.3 合并与逆向拆分

- **商品移动：**拖到空格只改变位置，不改变种类、等级或份数。
- **同种同级二合一：**两份原味一级合成一份原味二级，两份原味二级合成一份三级。不同产品或不同等级不能合并；原味不会合成焦糖。来源流水线不限，结果在目标格，原格腾空。拖向不匹配商品不合成、不丢货。
- **棋盘来源通用：**同种同级可跨线合并，交付不限制来源线；仓库仍各自独立，不能借库存发射。
- **逆向拆分：**仅在拆分已开放且等级高于一级时，手动将一份商品变成两份同种、低一级商品，保留一级材料等价量。一级不能拆，开放节点待定，当前订单不能依赖未开放拆分。
- **拆分空间：**额外需要一个空格，一份结果留原格、另一份进入空格。无空格时完全不执行，不扣原商品、不生成部分结果。可先交付、合并或免费丢弃其他商品腾位。不因低阶旧单增加必须拆分的前提。

### 5.4 免费丢弃与商品持有

- **取消回仓与免费丢弃：**商品上棋盘后不能返回任何流水线仓库，也没有棋盘外商品暂存格。玩家可免费丢弃指定商品：消耗该份商品、释放原格，不返库存、不返材料、不产生金币。棋盘满时可通过合并、交付或丢弃腾位，不依赖购买扩格。发射器仍常驻，不能通过收起发射器腾位。

- **既有棋盘商品有效：**匹配商品不要求在订单出现后才生产、发射、合成或拆分，已有棋盘成品可用于任一相关订单，各单共享、不预留。仓库仅提供待发商品和材料估算，不直接计入齐货。升阶舍余与丢弃的材料不能继续使用；没有订单时仍可生产、发射、合成、已开放的拆分和丢弃。棋盘与各线仓库分别记录实际持有商品，不重复保存。

### 5.5 发射落点顺序

每次发射都按当前棋盘状态重新寻找空格，以发射器所在格的中心为起点：

1. 按格子中心到发射器的直线距离，由近到远检查；距离相同，从正上方开始顺时针检查。
2. 周围8格先检查上、右、下、左四个紧邻格，再检查右上、右下、左下、左上四个斜邻格。都满后，继续按相同距离和方向规则寻找全盘其他空格。
3. 跳过越界格、商品格、其他发射器格及已被飞行动画占住的格子，不回绕棋盘边界。占用格不形成阻挡，不要求发射器与空格之间存在连续空格通路。
4. 附近腾出空格后，下一发优先回到附近；不沿用上次落点向后顺延。全盘没有空格时停止发射，玩家不能指定落点或出货区域。

### 5.6 点击、长按与拖动手势

以下为已确定的发射参数，实际触控和反馈仍待试玩验证：短按松手发一份，按住0.4秒触发长按首发，之后每0.2秒发一份；距最初按下位置移动超过10个屏幕像素时进入拖动。

- **按下与短按：**按下立即显示按压反馈并开始计时，不立即出货。未进入长按或拖动就松手，发射一份；连续有效点击每次各发一份，不累计尚未发出的请求。
- **长按：**按住不动达到0.4秒时先进入长按状态并发射第一份，随后匀速每0.2秒一份，不随按住时长加速。每一发重新检查库存、空格和落点。松手立即停止，松手时不补发。
- **拖动优先：**移动距离始终相对最初按下位置计算，允许阈值内的小幅抖动。超过10个屏幕像素就锁定为拖动，无需等待0.4秒；即使又移回原位置，本次也不能重新变成点击。拖动结束只完成放置，不发射。手指跨出原格后仍按这套位移规则判断。
- **连发转拖动：**长按发射中越过移动阈值，立即停止连发并转为移动；已经发出的商品保留，落下发射器不补发。
- **结束与重新开始：**本线库存不足一份、全盘满、松手、系统取消或离开页面时，结束本次连发；补货、腾位或回到页面不自动续发，需要重新按下。对应流水线出厂等级变化也结束本发射器连发；已经扣货并锁定落点的商品保留旧等级，未扣货请求取消，下次按下使用新等级。
- **单指控制：**一次手势只由最初按下的手指控制，其他手指不增加发射次数、不接续控制；首次手指松开后须有新的按下才开始下一次操作。

## 6. 单线升阶、仓库折算与旧批入账

### 6.1 成长价值与稳定出厂规格

出厂升阶是单条流水线的阶段性成长。提速或扩批改善供货；升阶让玩家从更高等级开始合成，减少熟悉的低阶操作。同种产品的其他流水线可保留原规格与库存，玩家可以同时经营不同等级的供货线。

- **升阶信息：**展示本线出厂等级变化、可用仓库折算后的份数及舍弃量，并说明完成同一目标所需的发射份数和合并次数变化。升级条件、费用与发射器外观变化暂不设计。当前订单所需材料必须能由已投产流水线供应，不能依赖未来升级或扩线。

- **稳定的高阶起点：**升阶后新批次默认稳定产出新等级商品，不用低概率掉落代替确定成长。产速、单批实际份数与出厂等级分别展示，不能将“份数不变”误认为合成价值没有提高；每份成品取到棋盘后各占一格，生产批量不改变这一规则。

- **兑现新起点：**升阶后以真实新规格库存和发射商品体现新的合成起点，并对照同一目标减少的发射份数与合并次数。

对应的成长节奏为：**熟悉当前合成链 → 攒钱完成出厂升阶 → 同样目标更少操作、交付更轻松 → 逐步接触更高等级的新目标 → 为下一次升阶积累。**

### 6.2 升阶时各对象的处理

| 对象 | 升阶后的处理 |
|---|---|
| 被升级流水线的新批次 | 从新出厂等级稳定生产，仍真实加工及包装 |
| 本线升阶时可用库存 | 按6.3节统一折算，完整份数保留、零头舍弃 |
| 本线已开工或待包装、未入库旧批 | 保留真实规格、物料与进度，按6.4节集合结算 |
| 其他同种流水线及其他产品 | 出厂等级、库存和批次不随本线改变 |
| 已有棋盘商品 | 种类、等级、位置保留，不参与仓库折算 |
| 已扣库存并锁定落点的飞行商品 | 已属于发射后的棋盘商品，保留旧等级；动画不再次扣货或生成 |
| 尚未扣库存的下一发及当前连发 | 未发请求取消，本线连发结束；重新按下后使用新等级 |
| 未完成订单 | 按8.4节重算产品最低出厂等级m，必要时只抬低阶需求，订单金币保持原值 |

仓库折算与旧批入账是指定自动转换；发射、棋盘合成、已开放拆分、丢弃与交单仍由玩家操作。普通提速或扩批不触发库存等级转换。除已确认的旧低阶目标调整外，不立即扩大普通新单劳动、降低同类奖励或减少服务次数来抵消成长；目标不变的熟悉订单应体现操作节省。

### 6.3 可用仓库统一折算

设流水线 i 当前或升阶后的出厂等级为 f_i，一份第 t 级商品的一级材料等价量为2^(t−1)。本线可用仓库、尚未入库的旧批集合与棋盘商品分别记录，不混算：

- **仓库升阶统一结算：**本线仓库各等级份数为n_(i,t)，先合计V_i=Σ[n_(i,t)×2^(t−1)]，新库存为N_i=floor[V_i/2^(f_i−1)]份第f_i级商品，舍弃量为V_i−N_i×2^(f_i−1)。同线不同等级先合计后取整；其他同种线和其他产品不参加。仅处理升阶提交时本线可用库存，不把棋盘、未包装产量或待统一入账旧商品加入。

### 6.4 旧规格批次集合入库

- **本线旧批集合统一结算：**升阶时记录本线已开工及待包装、尚未入库的全部旧批。原规格、物料与进度保留，每份仍须真实加工和包装。已包装整件保存为待统一入账记录，不可发射或交付；完成包装即释放原机器和包装缓存，不占住有限缓存等待其他旧批。集合全部包装完成后，合计其实际整件的一级等价量W_i，按本线届时等级一次增加floor[W_i/2^(f_i−1)]份库存，剩余零头舍弃。记录保存的是实际完整商品，不是已折算零头；新批正常入库，不受该集合等待限制。

### 6.5 折算实例与守恒

- **实例：**本线9份一级可用库存升二级得4份、舍弃1份一级等价量；直接升三级得2份、舍弃1份一级等价量；3份一级升三级得0份。其他同种线的库存不变。另有两个旧批各3份二级，升三级后等待两批全部包装完，合计6份二级折成3份三级入库；不能逐批取整造成额外舍余。

- **材料与结算关系：**发射、移动、合成和已开放的拆分保持一级材料等价量。仓库升阶与旧批集合入库分别核算，转换前等价量等于转换后等价量加舍弃量；已经舍弃的部分不保留、不累计、不借后续旧批恢复。丢弃消耗所选商品且不增加任何库存。在线、离线遵守相同批次范围与入账顺序，同一份商品只结算一次。

同一种产品的一份第t级商品对应2^(t−1)份一级材料等价量，每份在棋盘占一格。同种同级可跨线二合一，已开放的拆分为其逆操作，均保持材料等价量；发射和移动也守恒。单线仓库升阶与旧批入账允许指定舍余，丢弃直接消耗商品；这些损失分别记录，不再提供回仓转换。

### 6.6 已知边界与未定事项

- **结算边界：**已进入可用库存的商品随本线仓库升阶折算，不重新加入旧批集合；未分配给本线的公共基础物料不属于集合。旧批尚未统一入账时再次升阶，集合是否合并及结算时机留待细化，本轮不新增升级前置。发射器默认摆放位置仍待定，常驻、每线一个、每器一格及可移动已确定。

## 7. 合成成本、拆分成本与操作量

### 7.1 单份向上合成

在没有既有中间商品的条件下，全部从第s级起步且t≥s，生成一份第t级目标需要2^(t−s)份起始商品、2^(t−s)−1次合并。目标与所选线出厂等级相同时，只需发射到棋盘，无须合并。每产品订单目标不低于全部已投产线最低出厂等级m，但可能低于某条高阶线的f_i；此时可选择低阶线向上合成，不能将高阶线库存视作匹配成品。已有高阶棋盘商品可在拆分开放时手动拆分，公式不代表自动执行。混用不同线或不同起始等级时按实际材料重新计算。

| 出厂起始等级 s | 目标等级 t | 所需起始商品份数 | 合并次数 | 用于观察的体验 |
|---|---|---:|---:|---|
| 一级 | 五级 | 16 份 | 15 次 | 升阶前的熟悉目标 |
| 二级 | 五级 | 8 份 | 7 次 | 第一次升阶后，同目标操作明显减少 |
| 三级 | 五级 | 4 份 | 3 次 | 旧目标成为轻松交付 |
| 三级 | 七级 | 16 份 | 15 次 | 在较高起点上展开新的高阶目标 |

表中为严格二合一的关系示例，不代表已确定升级节点、商品等级上限、订单价格或完成时长。三级起步做七级与一级起步做五级的合并次数相同，但供货时间与实际奖励仍需依据设备和经济配置单独验证。

### 7.2 跨订单批量准备

每张订单中，每种产品的需求固定为一份，即该产品在单张订单内 q = 1。玩家仍可为多张订单批量准备同种、同级成品：累计准备 q 份、全部从第 s 级商品开始、t ≥ s 且没有既有中间商品时，需要 **q × 2^(t−s)** 份起始商品、**q × [2^(t−s)−1]** 次合并，最终得到 q 份第 t 级商品；若全部留在棋盘上，占 q 格。此处 q 为跨单批量准备的正整数，不是单张订单可调整的需求份数；已有中间商品或需要拆分时，应按实际供给重新计算，不能直接套用这组向上合成公式。

例如为多张各需一份原味三级的订单批量准备四份原味三级，从一级起步需16份一级原味、12次合并，最终4份成品各占一格；单张只消耗其中一份。累计材料不要求同时铺满棋盘，最终占格也不等于合成过程工作空间。即使某线仓库已有三级商品，也须逐份发射后才能交付。发射、移动与丢弃不计入合并次数，丢弃后补回同一目标所需的供货与操作另计。

### 7.3 完整及部分逆向拆分

在拆分已开放且 s > t 时，将一份第 s 级商品完整逐级拆到第 t 级，会得到 **2^(s−t)** 份第 t 级商品，需要 **2^(s−t)−1** 次拆分。每次拆分都须满足额外一个空格的条件；实际只拆出部分目标或使用已有中间商品时，按实际执行步骤计算，不要求将全部余货拆到同一级，也不自动拆分。

### 7.4 订单操作量约束

订单同时约束等待、发射份数、合并与拆分次数及占格，按产品种类数、各目标与可供货流水线等级的差距、真实材料缺口控制操作量。逐线考虑独立库存、规格和有效产速，以及棋盘中间商品与已开放的可拆分材料；跨线同级材料可在棋盘实际合并，但不能在仓库自动转换。已舍弃或丢弃的材料不再计入。单内每种一份，不通过扩大同种份数、额外抬高新单目标或增加混合种类来补回重复劳动；旧单低于产品最低出厂等级时的目标调整按已确定衔接规则执行。

## 8. 并行订单、备货与交付

### 8.1 自动出现、浏览与补充

多张订单自动出现并同时有效，每张绑定顾客，玩家无需接取，可自由安排准备与交付顺序。订单统一在棋盘顶部横向浏览，不新增独立订单页或收入渠道。单内产品规则见8.2节，最低等级衔接见8.4节。

- **自动出现与补充：**系统生成多张可完成的并行订单，不设接取步骤。交付一张只补充该位置，除已确定的升阶低阶需求调整外，其他未完成单均保留顾客、需求、金币和位置，不整组重抽；目标调整按后述规则执行。备货与顾客预告随实际结算更新。并行数量与补充节奏留待原型校准。

- **横向浏览与关注：**订单卡在棋盘顶部横向排列，超出屏幕的卡片通过左右滑动查看，玩家可边合成边选择当前关注的订单。选中状态清楚可辨，当前关注用于商品需求高亮、缺口及投资提示；选择或滑动不接取、交付、扣货或暂停其他订单，也不改变生产调度。横滑手势限定在订单区，避免与棋盘商品、发射器拖动混淆；不靠缩小卡片文字同时挤入全部订单。

- **卡片信息：**每张卡显示顾客头像、姓名、当前星级或新客标记、商品需求、已备份数与缺口、订单金币及本单对升星进度的推进；每项指定成品的备货进度显示为0/1或1/1，额外现货不增加本项需求。若本单达成升星，预告对应奖励。卡片区分缺材料、材料够待操作与成品齐备可交付，只有该单真实齐货时才提供可用的交付按钮。顾客数量足够时优先提供不同顾客，初始顾客较少时允许同一顾客同时有不同订单；每次完整交付一张只累计一次服务。

### 8.2 单内产品唯一、每种一份

- **单内产品唯一、每种一份：**“产品”指原味、焦糖、爆米花球、脆棒、薄脆、夹心脆方六种类别，同种产品的不同流水线和不同等级不计作不同产品。每单每种最多一项、一个目标等级、一份成品；“原味三级2份”或“原味二级1份＋原味三级1份”不生成，“原味三级1份＋焦糖二级1份”可生成。展示棋盘成品、各线待发库存、中间材料和缺口；仓库不计入0/1成品进度。初期集中一两种，逐步测试混合需求。跨订单可要求同种同级或不同级，跨单批量备货、生产批量和持有量可大于一。

### 8.3 材料预览、棋盘齐货与共享

- “材料足够，待发射／合成／拆分”与“棋盘成品齐备”分别显示。即使仓库有目标等级商品，尚未发射也只算待操作；一级等价量用于估算成本，不能代替指定等级的棋盘成品，不在交付时自动发射、合成或拆分。

- 单张订单的材料规划先分配棋盘匹配成品，再评估各流水线独立库存、低阶棋盘材料及已开放的高阶拆分路径。逐线使用其真实等级与数量，库存不自动跨线合并；材料发到棋盘后同种同级可跨线合并。单张订单内每份商品、库存和潜在结果只能分配给一条路径，不重复计算。各订单可分别评估共享材料，但不能相加预览声称全部订单同时已备齐。规划不扣货、不预留，随实际状态更新。

- 等待估算考虑同种产品全部流水线的规格、库存、独立加工及公共瓶颈，不能统一假定一级生产。各线旧批只有在本线集合全部包装完、统一折算入库后才计为可发库存；在制和待入账整件可估算后续供给，不计为已持有材料或棋盘成品，不同时重复分配来源及其转换结果。

只有棋盘上实际存在、种类和目标等级匹配的成品参与齐货与交付，不绑定来源线。仓库匹配商品也须先发射；订单出现前已发射、合成或拆分得到的成品同样有效。

各单可分别预览同一份未消耗的棋盘现货，不预留、不锁定。多张卡同时显示可交付，不保证这些订单可以连续全部交付。例如两单各需一份原味三级，棋盘仅有一份时都可显示1/1；交付其一后，另一张按剩余棋盘重算为0/1。

### 8.4 等级下限与升阶后的旧单更新

- **等级下限与旧单衔接：**每产品取全部已投产流水线最低出厂等级m，新订单逐项满足t≥m。某条线升阶后重算本产品m，检查全部未完成订单：该产品需求低于新m时，自动提高到m；其他需求、顾客、位置及订单金币奖励保持原值。随后按棋盘真实成品重算全部订单，可从齐货回退为缺货。只升非最低线或仍有其他低阶线、m未提高时，不改目标。新开一级线使m降低，也不追溯降低已存在目标。订单不绑定某条线，不取消、不重抽，也不依赖再购买新线或开放拆分来完成。

- **投资效果与目标更新：**顾客轮换、重进、关注切换和新客开放不替换未完成订单。只有产品最低出厂等级提高时调整受影响旧需求，订单金币保持原值；棋盘旧成品保留，但可能不再匹配新目标。新开低阶线不下调旧目标。普通新单保持阶段性稳定需求，不额外放大操作量、降低同类奖励或减少服务次数来抵消成长；分别评估目标保持和目标提高两类旧单的实际体验。

### 8.5 整单交付与一次性结算

- 某张订单所有需求在棋盘齐备后，等待玩家点击该卡交付按钮。提交时重新校验订单目标、完成状态和棋盘真实商品，每种所需产品只扣一份指定等级棋盘成品，统一整单结算。共享商品已被另一单消耗或目标因升阶调整而不再匹配时，不部分扣货，更新缺口。每份被消耗商品释放原格，其他商品保留位置和等级；交付不从任何仓库扣货。扣货、格位释放、完成标记、订单金币、一次顾客服务与当次达标升星礼同次执行且只执行一次。交付后立即按剩余棋盘商品重算其他订单。

- 沿用整单交付，不增加分批交付或订单预存。等待其他商品时，已备成品留在棋盘持续占格；也可免费丢弃指定商品腾位，丢弃不返库存、不产生金币。取消回仓，不增加棋盘外商品暂存格。

齐货未提交时不扣货、不发金币、不增加顾客服务次数。只有玩家点击某张订单的交付按钮并通过重新校验，才扣棋盘成品并结算一次完整服务；当前仓库不能作为交付来源。

该单收入与当次顾客升星礼在同次结算中发放，图鉴不另行领取。重复点击、重进游戏或返回图鉴不重复扣货、发金币、累计服务或发节点奖励。同一顾客的其他卡预告按实际服务进度刷新，详见第9章。

### 8.6 交付算例

例如订单要求“原味三级1份、焦糖二级1份”，两条流水线均从一级出货时，需要四份一级原味与两份一级焦糖，共四次合并。若原味已升为二级出厂、焦糖仍为一级，则需要两份二级原味与两份一级焦糖，共两次合并。交付的始终是指定等级的实际成品，不能用等价材料直接提交。

再如订单要求原味三级一份，棋盘有四份原味三级，提交后只扣一份、释放一格，剩余三份保持原位置与等级。若只有一份原味四级，即使拆分已开放也仅算可拆分材料；实际拆成两份三级后才齐货，交付一份、另一份留盘供其他订单使用，也可免费丢弃。只有仓库三级而没有棋盘三级时仍不能交付，须先发射。算例不代表固定奖励配置。

### 8.7 生成约束、奖励与选择

- **始终可完成：**每单仅使用已投产产品和已开放等级，逐项t≥m，现有线可持续提供向上合成所需材料，不要求未来升阶、新开线、未开放拆分或持续点击。每种最多一项且只需一份，生成时同时核对供货等待、可选线等级、整单合并量和实际常驻发射器数。六种产品全开放后单张最多六份不同成品，不默认六产品混合单；整单成品全部须能同时在棋盘，且合成过程有足够工作空格。商品不能回仓或盘外暂存，可交付、合并或免费丢弃腾位。无需全部并行单同时留盘，当前组合至少一单适合短时游玩。升阶时旧低阶目标按m更新，使供货路径继续存在，不要求靠拆分兜底。

- **并行目标有差别：**各单可偏向现有材料充足、较少操作或匹配出厂等级发射后可交付的目标，也可要求进一步合成的高阶目标。不同规格线让玩家选择取货起点；各单在近期回款、操作投入和投资方向上有实际差别，不要求先交指定一单才能操作其他单。

- **顾客提供收集取舍：**在上述经营取舍之外，玩家也可选择先结识新顾客，或服务接近升星的老顾客。顾客身份不固定对应简单或困难订单，订单生成仍须保证可完成性与合理操作量，不能为了凑新客或熟客而生成无法供货的需求。

- **奖励与真实投入：**新单按各产品一份指定成品的材料等价量、供货能力、可选合成起点和操作投入估值，不只按标示等级线性计价，也不以单内份数调难度。既有订单因m提高而修改目标时不重新估值，订单金币始终保持原值；这类订单的新材料成本与回报单独评估，不能自动涨奖。目标不变时，升阶减少操作应形成效率收益，不按少做的合并次数即时降奖。阶段价格表留待验证。

- **回报与节奏：**订单回报应支持有感知的产能投资或推进扩建；通过产品组合、等级、可选线及材料缺口提供取舍，不依赖持续点击或大量低阶拖拽。每种一份规则结合交单频率校准金币与顾客成长，不额外抬高新单目标、扩大混合种类来补回劳动；旧单目标更新仅按等级下限规则执行，每次完整交单仍只增加一次服务。

- **允许离开：**订单不设失败倒计时，暂停游玩保留全部未完成订单、当前关注订单、库存、棋盘和顾客进度。货齐后可等待玩家回来提交，不因延迟交付损失商品、降低顾客星级或让顾客永久离开；横滑或重新进入游戏不刷新订单。

## 9. 顾客图鉴与熟客升星

顾客是跨多张订单持续存在的收藏对象，每张订单只记录其中一次服务。基本循环为：**获得来访资格 → 出现在并行订单中 → 首次交付点亮图鉴 → 重复服务累计次数 → 升星并获得一次性奖励。**

### 9.1 来访资格与首次收录

- 开局提供能购买原味的初始顾客，后续随产线投产和工厂阶段配置分批开放来访资格。一种产品可对应多名顾客，六种产品不限制只有六名顾客；具体名单、数量与开放节点另行配置，本轮不调整同种扩线对应的顾客开放配置。
- 获得来访资格代表能够出现在后续订单中，不直接算作收集成功。只有首次完整交付该顾客的订单，才点亮图鉴并达到一星；订单出现、横滑查看、选为关注目标或仅备齐商品均不点亮。
- 尚未优先服务的新顾客保留来访资格与已出现的订单，不因玩家先交其他订单便永久错过。工厂扩建与出厂升阶不以图鉴收集数量、某位顾客星级或满星为前置条件。
- 每名顾客有形象、姓名、介绍和一两种产品偏好，偏好指产品类别；具体组合与目标按已投产内容、同种全部线的规格及订单规则生成，每种一项一份，不将某顾客固定为永远买一级，也不因升星立即提高其所有需求。

图鉴记录已收录人数与当前内容总人数，并区分以下状态；查看图鉴不发放第二份交单或升星奖励。

| 状态 | 图鉴展示与含义 |
|---|---|
| 尚未开放 | 剪影、简短线索与开放条件，提供后续收集目标 |
| 可来访但未服务 | 新客预告与首次交单提示，不计入已收录人数 |
| 已经结识 | 形象、姓名、简介、产品偏好、星级、累计服务次数及下一星进度 |
| 已满星 | 保留完整档案与满星标识，明确已完成该顾客的星级成长 |

### 9.2 服务次数与升星

- 首版原型先采用五星上限；正式星级上限、各星所需累计次数与奖励数值留待试玩校准。首次成功交付计为累计服务一次并达到一星；后续按递增的累计次数门槛逐级升星，升星不清空已累计次数。
- 每完整交付该顾客的一张订单，服务次数加一，不按商品份数、合并或拆分次数、金币金额重复计数。横滑切换关注、服务其他顾客、离线和延迟交付均不减少或清空进度，也不要求连续完成同一顾客的订单。
- 订单卡与图鉴使用同一份顾客进度，清楚表达本单完成后的变化，例如“再服务一次升星”。若同一顾客有多张并行订单，一张交付后立即刷新其他卡的星级、服务进度与升星奖励预告；预告按当前真实进度判断，不提前累计未交付订单。顾客星级与工厂代际、出厂等级、商品合成等级分别标示，互不代替。
- 满星后仍可出现该顾客的正常订单，交付仍赚取订单金币并记录服务次数；星级不再增加，已完成的星级节点不重复发奖。
- 出厂升阶让熟悉订单更易完成时，仍获得完整的一次服务进度。简单订单可用于较快培养熟客，复杂订单的较高投入主要由订单金币体现；通过并行订单组合与回报校准优先服务的选择价值，不额外引入熟客积分或好感货币。

### 9.3 一次性奖励与反馈

- 每个顾客的每个星级节点提供一次性金币礼；首次收录的一星礼属于同一个星级节点，不另算一份重复首单奖励。星级、图鉴点亮与进度展示作为长期收藏成果。
- 达标时，升星与奖励随该次手动交单一起结算，以结算时该顾客的真实服务进度判断，清楚列出“订单收入”和“本次升星奖励”，记录该节点已经发放。同顾客各卡的预告均表示按当前进度交付该单的结果，不为该卡锁定奖励；多张卡曾预告同一节点时，该节点仍只发一次，交付一张后其余预告随之更新。图鉴用于查看成果与下一目标，不增加独立领奖回款、每日收益或永久金币与产能倍率。
- 服务次数、图鉴收录、星级、节点奖励发放与订单完成保持一致；重复提交、重进游戏或再次打开图鉴均不增加次数或重复发奖。
- 升星反馈短而明确，随后可继续下一单。奖励应帮助一次有感知的经营成长，同时纳入整体金币产出评估；未触发升星的普通订单也应能支持正常升级与扩建，不把等待某位顾客作为必要收入门槛。

### 9.4 新客与熟客轮换

- 生成初始订单或交付后的补充订单时，在已获得来访资格、且当前能够生成有效订单的顾客范围内选择。兼顾待收录新客、久未出现的老客与未满星顾客，不仅依赖均匀随机抽取，避免图鉴扩大后熟客长期无法继续升星；具体轮换优先级与补充节奏留待原型验证。
- 有新客可服务时，安排新客与熟客都能获得出场机会；全部并行订单还需满足现有的投入、回报和供货约束，当前组合中至少一张符合当前产能与短时游玩目标。
- 满星顾客继续保留，但仍有可服务的未满星顾客时，不让补充订单长期只来自满星顾客。未完成订单不因轮换、重进游戏或新客开放而重抽；交付后只为已完成的位置生成补充订单，其余顾客及订单保留。
- 顾客轮换只决定订单归属，不增加接待、排队、顾客等待倒计时或额外操作入口。本版不展开顾客介绍朋友、纪念物、主题图鉴组合等延伸玩法。

## 10. 页面职责、信息与连续反馈

### 10.1 操作场景与经营信息

界面分别说明产能投资对等待的影响，以及单线升阶对本线规格、仓库折算、旧批结算与同目标合并量的影响。依据各线独立库存、等级、实际产速、棋盘中间商品及已开放拆分识别缺口，不因每种只需一份就认定投入相同。材料已足时可选择发射、合成或已开放拆分，不强迫升级；仓库有匹配成品也须先发射。升阶仅转换本线库存，其他线及棋盘商品保留，再按产品最低出厂等级检查旧单目标更新。

订单提示以当前关注目标为依据，也说明投资对同产品其他订单的影响。切换关注不预留商品、不改变调度；各单共享棋盘真实现货。材料预览可分别评估各线库存，但库存彼此独立，不能直接用作订单成品或重复声称已备齐全部订单。

经营取舍包括加快缺货线、改善公共包装、提高某条线合成起点、增开同种线或更早扩建新品。棋盘顶部横滑订单区展示关注目标、棋盘可交付成品、各线待发库存、金币及投资目标，同屏突出最相关信息。公共基础份额的分配方式仍待定，提示不预设多开某产品必然获得更多全厂份额。

棋盘是发射、合成、拆分和丢弃的主要操作场景；工厂用于观察加工、定位瓶颈和投资，顾客页用于查看收集与熟客成果。工厂页的已齐订单入口仍按同一棋盘现货和同一结算结果执行，不直接从仓库扣货。具体页面布局、设备选择与加速入口见[工厂主页面设计](factory-main-page-design.md)。

### 10.2 合成、拆分与交付反馈

每次合成同步表现新物品出现、原格腾空及相关订单进展。首次合成新等级强调可辨识的形态变化；连续合成允许玩家顺畅接续，不用反复弹窗或强制等待长动画。订单所需物品与等级明确标识，减少把已满足需求的物品继续合高造成的误操作。

商品种类与等级始终清楚可辨识，每份占一格；合成反馈表现为两份同种同级商品变成一份高一级商品并腾出一格，拆分反馈表现为一份商品变成两份同种、低一级商品并多占一格，同时更新实际份数和订单状态。交单时展示已扣除的商品与释放的格位，未交付的商品保留原位置与等级。

基础产量和早期订单应支持一轮取货后完成几次连贯合成，避免每次只够合一下就再次等待。交单时对应物品离场、金币集中到账、顾客服务进度增加，同时刷新其他并行订单的备货进度与相关顾客预告；首次收录或升星在同次反馈中突出，随后清楚展示可进行的产能投资或扩建差额，不用连续强制弹窗打断后续操作。棋盘是主要操作场景，顶部订单卡横向排列，玩家可边合成边滑动查看各单；工厂用于观察加工、查找供货瓶颈和投资。从棋盘能看见当前关注订单所需产品的库存与缺口，不靠频繁切页维持操作。

## 11. 游玩节奏与离线生产

### 11.1 待验证的节奏目标

以下节奏和收益要求均为待验证的设计目标，不代表已经实测达成。后续通过数值模拟和试玩校准，本轮不执行模拟：

- **单次游玩：**以几分钟的短时登录为主要场景，在棋盘顶部横滑查看并行订单，选择当前关注目标、取货、完成一段连贯合成、手动交单并安排下一笔投资，同时看见新客收录或熟客进度。允许玩家只推进其中一张或部分订单后离开，全部未完成订单、棋盘与顾客进度保留，不以持续在线或固定操作频率作为要求。
- **首轮体验：**开局自动出现的订单组合中，至少一张可由初代设备供应原味产品，并包含低等级合成目标。在首轮短时游玩中体验横滑查看、取货、二合一、手动交付、首位顾客收录及一次有明显效果的投资，无需先接单。点击作为可选加速介绍，不作为取得首次金币的必要操作。
- **自动与主动平衡：**自动产能应支持合理材料等待，玩家选择流水线发射，再合成或按需使用已开放拆分。仓库匹配成品也必须发射，商品及常驻发射器各占一格。普通新单配置不按持续高频点击定价，也不额外扩大劳动抵消提速或升阶；旧低阶目标调整按m执行、订单金币不变。分别验证供货等待、库存充足时操作和升阶前后体验。
- **等待与退出：**早期通过订单需求、交付回报和基础产能配合缩短无决策空档。基础材料不足时可自然离开等待库存积累，也可自愿点击补缺口；回归后继续合成与交付，不要求守候下一件原料产出。
- **代际、扩线与升阶节奏：**新品首次投产增加产品类别；同种扩线增加独立加工设备、库存和常驻发射器，并从一级起步；提速改善等待，单线升阶提高起点。旧单低于新m的需求提高、奖励保持，其他熟悉目标应体现操作节省。升级条件、费用与发射器外观变化暂不设计；拆分开放节点待后续确定。
- **收集节奏：**新产品首次投产带来新顾客机会，重复服务推进老客升星，控制新客与熟客回访节奏，不要求集齐或满星后继续经营。
- **整体时长：**目标为六种产品依次首次投产，并体验每种最多三条线的独立库存、供货起点及已开放拆分。具体开线数量由玩家选择，不要求全部18条建满。按供货、发射、合成、拆分、丢弃、投资、交单与回归校准节奏，不预设必须在线时长，不用重复劳动或高费用拖长流程。
- **新机教学：**用首批自动加工和入库展示工序，再通过取货与首次合成认识新产品的独立等级链。按需提示订单缺口、供料与包装关系以及可选点击效果；无需完成机器手工批次或守候设备。

成长价值体现为各线自动积累材料、选择规格取货、跨线同种合并形成成品、交单获得金币与顾客收藏；提速减少等待，单线升阶提高起点，同种扩线提供独立加工与不同规格选择，新品扩建增加产品链和顾客机会。商品无回仓，免费丢弃用于腾位。高阶内容按可选起点、等级差及产品组合校准，每单每种一份，允许自然退出和回归。

### 11.2 离线生产与状态保存

- **离线积累：**默认最多计算 **2小时**自动生产，所有已投产线参与，按各线真实规格、加工能力及公共供料与包装限制分别增加独立库存，不得直接获得金币、补算点击或自动发射。旧批集合与在线同规则：全部实际包装后按本线届时等级合计一次折算入库、舍余；未全部完成不算可用库存，已包装整件记录保存并释放物理缓存，新等级批正常入库。回归先结算一次真实离线产出，再主动升阶时只转换本线库存，不补算第二份离线收益。

- **离线产能：**统一受公共供料、加工、包装能力限制，不能将各流水线的独立满产产量直接相加。

- **离线期间：**保存每线独立库存、原批规格与进度、旧批集合和已包装待入账整件；棋盘保存商品及发射器对应流水线、产品、等级和位置，未完成订单与关注目标保留。离线不自动发射、移动、合成、拆分、丢弃、交付、补单、重抽、购买升级或新开线，因此不会凭离线购买升阶或改订单目标。已发起的旧批集合可随真实包装完成统一入账，只结算一次。未建设线不参与生产，顾客进度不因离线备料提前增加。

### 11.3 离线订单与回归

- **离线订单：**离线仅补充各线仓库，不直接增加棋盘成品。库存增长可使订单由缺材料变为材料够待发射／合成／拆分，缺失的棋盘成品不会因仓库补足自动齐货。原有棋盘匹配成品仍有效，各单可共享预览，不预留；回来逐张交付后刷新其他单。工厂在两小时内继续真实生产，不因材料已够或已有棋盘成品停止累计。

- **回归反馈：**按产品、流水线、等级和实际份数展示新增库存，区分缺材料、材料够待发射／合成／拆分及棋盘齐货。未完成目标、关注与顾客进度保留。缺失棋盘成品时从所选线发射，即使库存已是匹配等级也须上盘；此前连发不续发。手动交单只扣棋盘商品并释放格位、结算金币与顾客成果，再刷新其他单。回归后主动升阶时单独展示本线折算与舍余，并按m更新受影响旧需求，订单金币保持原值，不重算离线产量。

## 12. 原型验证顺序与设计验收

### 12.1 原型验证顺序

#### 阶段一：基础循环与不同合成起点

先用7×9棋盘、两种产品及各自发射器、一级出厂与一至五级目标，验证“点击／长按发射—连续合成—交单—投资”的完整循环。覆盖近处与远处落点、满盘停发、长按转拖动和松手不补发。然后加入一级到二级、再到三级的出厂升阶试验，对比同一五级目标的操作量，并以三级起步的七级目标验证后续高等级内容；这些等级用于原型对照，不代表正式升级表。

在相同供货起点下对照单产品与混合订单，一格一份。从一级做一份三级消耗4份材料、3次合并，跨单准备4份则16份材料、12次合并、成品占4格，不能生成单张同种四份订单。固定目标和供货只提高一条线等级，比较合并量与奖励；另区分最低等级提高触发旧目标调整的情况，其金币保持原值。

#### 阶段二：折算、旧批、拆分与丢弃

加入单线库存折算，核对本线多档材料先合计后取整、舍余、其他同种线及棋盘不变；本线旧批全部包装后统一入账，已包装整件释放缓存，未完成集合不计可用库存，避免重复入账。再加入已开放的手动拆分及免费丢弃，覆盖一级不可拆、空间不足不执行、逐级拆分、拆后再合；丢弃只消耗指定商品腾位，不返库存。拆分开放节点仍待定。

#### 阶段三：全部产品与同种扩线

随后加入全部六种产品与同种扩线，每种最多三条、各线独立加工和库存、一级起步上限六级；各一线时六器57商品格，全部三线时18器45商品格，全部常驻。检查跨线同种同级合并、单线升阶、按m更新旧低阶需求且奖励不变、只从棋盘交付、免费丢弃恢复满盘及离线旧批入账。容量按单张整单及合成过程核对，不要求全部并行单同时留盘，该顺序不减少最终六种产品内容。

#### 阶段四：并行订单与顾客养成

在同一套订单循环中加入多张自动出现的并行订单，验证棋盘顶部横滑查看与关注切换、无需接取、共享商品不预留、单张交付后的其余订单进度回退、补充新单与未完成订单保留。覆盖两张同需求订单共享一份成品并连续提交，确认每次按真实剩余商品结算。再加入少量顾客，验证首次收录、重复服务、升星一次性奖励与新老客轮换；同顾客多张订单中，一张交付后其余卡的服务进度和奖励预告同步更新。对比“新客首单”和“老客差一单升星”的并行目标，观察顾客目标是否真实影响交付顺序；随后扩大顾客池，检查熟客回访与满星后的订单组合，不扩展其他顾客玩法。

#### 记录与比较指标

记录每单供货等待、各线选择、实际发射与材料份数、合并与拆分次数、丢弃次数及丢弃材料等价量、发射器占格和成品占格。分别比较同目标升阶与旧目标按m提高后的收益、操作与重复感，结合等级差、混合种类和跨单需求校准。在相同时间或投资目标下比较交单频率、等待、订单金币、顾客服务与剩余库存，不以更高数字或更多拖拽认定内容增加。

### 12.2 设计验收标准

以下用于后续实现、数值模拟和试玩验收，本轮仅更新标准，尚未执行这些验证：

#### 自动生产与加速

- **开局与新线直接运转：**从初代到六代，投产即自动完成供料、加工、转运、包装与入库；不要求先完成指定点击次数、购买自动化或守候翻面。
- **点击即时有效：**有可加工批次时，每次点击对应真实进度和机器反馈；停止点击后自动生产继续。检查不同设备等级下的点击价值，避免后期需要大量操作才能推进少量缺口。
- **点击作用于实际瓶颈：**分别覆盖缺料、加工慢、包装积压的情境，验证当前关注订单的提示和对应设备入口准确；评估该单整单备货时间的变化，不只看被点击机器的名义产量。横滑切换关注不改变公共生产调度或分配库存。

- **自动供货不依赖点击：**玩家通过所选线发射并完成必要合成，自动生产可供应有效订单材料；逐产品需求t≥同种已投产线最低等级m。仓库或可拆分材料不能误算棋盘齐货，匹配出厂成品须发射后才可交付。

- **零金币仍能完成订单：**现有线可供材料，发射、合成、已开放拆分和丢弃均不收费、不耗体力。没有可合对子且满盘时可免费丢弃恢复，不返库存；不能要求先买升阶、新线或开放拆分才能完成当前单。最低出厂等级提高时，旧低阶目标按m更新，订单金币原值保留。

#### 产品、等级、订单边界与批次

- **各线独立与跨线合成：**同种同级商品可跨流水线二合一，其他种类或等级不合并；每份一格，内容满级不再合并。新品首次投产增加类别，同种扩线不增加类别，最多三条独立加工线，各自一级起步、最高六级。升阶只转换本线仓库与新批规格，其他同种线及棋盘不变；旧批按本线集合处理。
- **成长确实减少重复操作：**同一五级目标从一级、二级、三级起步分别15、7、3次合并，真实产出与说明一致。目标不变的熟悉订单应体现减负；另核对t<m旧需求更新为m且奖励不变，不额外扩大普通新单劳动抵消成长。

- **高阶内容承接新起点：**比较相同等级差下的新旧目标，检查取货与合并量、外观发现及奖励是否合理；不能只提高目标等级而继续要求从一级反复合成。
- **单内产品唯一且每种一份：**初始、补充和各顾客订单按六种产品类别校验，同种不同流水线不是不同产品；每种一个目标等级、需求恒一。“原味三级2份”和“原味二级1份＋原味三级1份”不生成，原味与焦糖各一份可生成。成品进度仅0/1或1/1，只认棋盘。跨单需求、库存、批量和棋盘持有量可大于一。

- **批次与物料一致：**旧批保留真实规格、物料与进度，新批按本线新等级加工。本线升阶前已开工和待包装未入库旧批全部实际包装完后合计一次按届时等级入库舍余；待入账整件释放物理缓存，不提前算库存或成品。连续升阶时未结清旧批的处理仍待细化。线上、离线按同一边界结算，分别核对生产、仓库转换、旧批入账与舍余，每件只入账一次。

#### 棋盘、发射器、折算与腾位

- **棋盘与发射器容量正确：**横7列、竖9行、63格；每产品最多三条线、每线一个常驻一格发射器，可移动、不可收起。六器57商品格，18器45商品格，空格还须扣除真实商品与动画锁定落点。仓库和待入账记录不占棋盘；移动不覆盖商品，落下不发射。
- **发射落点固定且可预判：**按格子中心直线距离由近到远查找，同距从正上方顺时针；周围先上、右、下、左，再右上、右下、左下、左上，近处满后搜索全盘。覆盖边缘、角落和附近腾位，跳过越界与占用格，其他商品和发射器不阻挡远处空格，玩家不能指定区域。
- **点击、长按与拖动不混淆：**短按松手只发一份；0.4秒长按首发，之后每0.2秒一份，松手不补发。位移相对最初按下位置超过10个屏幕像素锁定拖动，连发转拖动立即停发，回到原处或落下都不补发。多指不接续控制，库存不足、满盘、取消或离开页面后需重新按下，补货及腾位不自行续发。
- **发射与库存扣除一致：**每发检查对应流水线一份当前等级库存和一个空格，成功时本线扣货与锁定落点同时执行，不借其他库存；失败不扣货。动画不重复占位，发射固定本线等级。升阶时已扣货发射保留旧等级，未扣货请求取消，重新按下才使用新等级。
- **库存折算和舍余准确：**只合计被升级流水线可用库存等价量，向本线新等级取整，其他同种线和其他产品不参与。本线9份一级升二级得4份、升三级得2份，其他线数量不变；转换后等价量加舍弃量等于转换前量。旧批集合全部包装后另行统一结算，不恢复已舍弃材料。取消回仓，免费丢弃不产生任何库存。
- **逆向拆分守恒且可恢复：**已开放时高阶一份拆为同种低一级两份，各占一格，一级不可拆，材料等价量守恒。没有额外空格不扣原商品，可先免费丢弃其他商品腾位；覆盖未开放、逐级拆、拆后再合与重进，不能重复生成。完整逐级拆的数量和次数按公式核对。
- **多线满盘可恢复：**覆盖六器及18器、同种不同规格和多产品混杂、没有可合对子、订单未齐且零金币的满盘。发射停止不扣货，可免费丢弃指定商品释放原格，不返材料、不返库存、不产生金币。腾位后须重新按下，生产继续入独立仓库，不要求付费扩格或收起发射器。
- **连续合成有反馈：**检查一轮取货后的连续操作、新等级辨识、腾位与订单点亮，商品种类、等级和一格一份的占用关系清楚；拆分只在实际执行后更新结果与订单进度，避免频繁强制弹窗或只有等级数字变化。主要操作无需在棋盘与机器页面间反复切换。

#### 操作量、订单交付与回报

- **操作量可接受：**比较材料不足、库存充足、不同可选线起点、混合种类与跨单准备，记录发射、合并、拆分、丢弃及其材料损失和占格。每单每种一份，区分同目标减负与按m提高旧目标的情况，不额外提高普通新单等级差、混合种类或补单频率恢复原重复劳动。
- **订单引导有依据：**同一需求在各线等级、库存、产速及棋盘材料不同的状态下，缺口建议使用真实可行路径。仓库成品必须先发射，不误报齐货，不强迫升级或未开放拆分。升阶说明本线折算、旧批等待及可能的m变化；关注切换不改变调度、目标或材料归属。
- **订单选择与回报合理：**新单仅使用已投产产品、开放等级，至少一单适合当前产能和短时节奏；新单定价评估材料价值及操作回报。旧单因m提高而调整需求时，金币保持原值，单独观察新成本与回报，不自动涨奖。顶部横滑与关注不接单、不扣货、不重抽，玩家自由选择交付顺序。
- **库存与交付明确：**各线库存、在制和旧批待入账仅用于供货等待及材料估算，不作为交付来源。订单只使用棋盘实际匹配成品，每种一份；仓库匹配成品也须先发射。单内不重复分配商品和潜在结果，多单可预览同一棋盘现货、不预留。未齐货不扣货，齐货未提交不发金币；提交时重新校验棋盘及最新目标，整单只结算一次，仓库不因交付增减。
- **交单只扣所需商品：**棋盘有四份原味三级、需求一份时只扣一份、释放一格，其他三份原样保留。只有仓库匹配成品时不能直接交付，发射后才可交；覆盖多产品整单、未使用商品、重复提交、同需两卡共享一份棋盘成品。首单交付后另一卡变缺货，每种只扣一份，奖励与顾客服务只执行一次，只补已完成位置。

#### 顾客、经营与扩建

- **顾客收录条件明确：**区分未开放、可来访未服务、已收录与满星状态；只有首次成功交付点亮图鉴并累计一次服务，订单出现、横滑查看、关注切换、材料齐备或离线不提前收录。尚未优先服务的新客保留机会，经营升级不依赖顾客满星。
- **熟客进度准确且保留：**每张完整交付的订单只为绑定顾客增加一次服务；订单卡与图鉴进度一致，切换关注或顾客、离线或延迟提交不清零。同顾客多张并行订单中，交付一张后其余卡的星级、服务进度与升星奖励预告立即重算。满星后仍能正常交单赚钱，原节点奖励不再触发。
- **升星奖励只发一次：**检查首次一星、后续升星、重复提交与重新进入图鉴等情境。订单收入与星级奖励分别展示但在同次交单结算，节点记录与服务次数一致；不重复发放首单和一星礼，不通过图鉴额外回款。
- **顾客轮换能支持收集：**扩大顾客池、开放新一批顾客并出现部分满星后，检查新客收录、老客回访与接近升星的顾客是否都有可达进展；当前并行订单组合中至少一张符合当前产能和合理操作量。补充订单兼顾新客与熟客，重进游戏不重抽未完成订单，不要求赶时间接待。
- **顾客与经营选择兼容：**验证新客首单、熟客升星、快速回款和高阶回报之间存在实际取舍；不能让最低成本订单在所有收益上长期占优，也不能因升星降低工厂蜕变收益。普通订单在无升星奖励时仍能支撑成长，顾客星级不直接充当商品难度等级。
- **旧能力持续有效：**各线接入既有物流，已购产能能力保持有效，不单独收费开启自动化。原产品仍可生产、发射、合并和交付，本线升阶只折算本线仓库并衔接本线旧批，其他线不受影响。旧棋盘商品保留，订单进度按最新目标计算。
- **扩建与同种扩线有区别：**新品首次投产新增类别及对应订单、顾客机会；同种扩线新增独立加工、库存和常驻发射器，从一级起步、每种最多三条，形成规格和投资选择。实际产量受公共供料包装限制，不将流水线数量直接当作产量倍率。
- **公共生产能持续推进：**已投产线获得可持续供料包装是设计目标，缺料或满缓存线不能阻塞其他可加工线。按产品还是按流水线分基础份额以及剩余能力分配继续待定，本轮不验收未经确定的优先级或份额数值。

#### 回归体验、离线与完整结算

- **短时登录有收获：**分别检查首轮、材料足够待合成、订单成品齐货及仍缺原料的回归。玩家能看懂状态、完成一段合成或自然离开，交单后安排投资；不以点击或拖拽次数充当成长成果。
- **节奏允许自然退出：**订单不设失败倒计时，玩家无需守候齐货或按固定频率操作。记录自动供货、主动加速、合成、交付和投资的分布，据此校准需求、回报及总流程，不通过抬高需求强迫点击或重复合并。
- **机器具有区别：**六代的物料变化、机器运动和出料方式不同，统一点击操作仍能呈现各自加工过程，并改变对供料、集中出料或连续生产的关注重点。
- **暂停操作没有惩罚：**停止点击、发射、合成、拆分或丢弃，等待、缓存满与离线不造成坏货、额外扣料或不可恢复堵塞，棋盘商品及发射器位置保留。主动升阶与旧批结算按规定舍余；主动丢弃消耗指定商品不返库存，不将其混为离开惩罚。
- **离线回归能继续推进：**覆盖各线独立等级与库存、旧批集合、已包装待入账整件、新批和满盘，按同一规则核算在线与最多两小时离线。离线不发射、不合并拆分或丢弃、不交单、不购买升级或开线，棋盘不变，金币不变。回归先结算一次各线库存和旧批入账，再逐张只交付棋盘成品；主动升阶独立转换本线仓库，并按m调整受影响目标、金币原值不变。连发不恢复，超过上限不额外生产。
- **生产、发射、折算、顾客与金币一致：**每线真实加工与包装只记一次产量，发射只扣本线库存并占棋盘格。合成拆分守恒，仓库升阶及旧批入账分别核算舍余，丢弃记录商品损失且不返库存，交付只消耗每种一份棋盘匹配成品。单内不重复计算商品或潜在结果，多单预览可共享但实际不能重复消耗。交单增加一次服务、发放订单原值金币与当次升星礼，重复操作和重进不重结算。升阶时仅按m调整旧低阶需求而不重算奖励；接取不再需要，发射、合成、拆分、丢弃、交单和投资仍由玩家操作。
